# Supporting Assets

This folder contains supporting visual material for the Large-Scale Data Pipeline case study.

The purpose of this folder is to provide additional project context without exposing confidential production information.

## Potential Assets

Examples of suitable materials include:

- Sanitized screenshots of reporting or analytics outputs
- Redacted execution or workflow examples
- Supporting documentation images
- Non-confidential visuals used in the case study
- Simplified representations of operational processes

## Excluded Content

This folder does not contain:

- Production datasets
- Customer or passenger information
- Credentials or authentication details
- Internal URLs
- Proprietary mapping tables
- Confidential business rules
- Production database information
- Sensitive company screenshots

## Confidentiality

Any visual material added to this folder must be reviewed before publication to ensure that confidential or personally identifiable information is not exposed.
